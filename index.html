100 ohm ±5%

วงจรอนุกรม (Series Circuit)

วงจรที่ต่ออุปกรณ์ไฟฟ้าเรียงต่อกันไปในเส้นทางเดียวกัน ทำให้กระแสไฟฟ้าที่ไหลผ่านตัวต้านทานทุกตัวมีค่าเท่ากัน

สูตรคำนวณหลัก:

1. R_total = R1 + R2 + R3

2. I_total = I1 = I2 = I3

3. V_total = V1 + V2 + V3

วงจรขนาน (Parallel Circuit)

วงจรที่ต่อคร่อมจุดร่วมเดียวกันทำให้แรงดันไฟฟ้าตกคร่อมตัวต้านทานทุกตัวมีค่าเท่ากับแรงดันแหล่งจ่าย

สูตรคำนวณหลัก:

1. (1 / R_total) = (1 / R1) + (1 / R2) + (1 / R3)

2. V_total = V1 = V2 = V3

3. I_total = I1 + I2 + I3
